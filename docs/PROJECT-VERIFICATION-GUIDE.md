# Project evidence guide

This profile includes source repositories, synthetic guest walkthroughs, and hosted demos. These are different kinds of evidence.

- **Source:** implementation and documentation, not necessarily a public running service.
- **Guest walkthrough:** illustrative interactions using synthetic records, not access to protected application accounts.
- **Hosted demo:** a live application URL; availability and behavior still require independent checking.
- **Private repository:** a public case study does not imply access to its code.

Before sharing with recruiters, verify links in a signed-out browser, open the official resume PDF, and compare claims with the implementation. Record CI links and dates for test claims. Do not equate local test results with deployment reliability.
